# Blackbaud Next

A clearer, more useful Blackbaud student portal.

Blackbaud Next is a Chrome extension that improves Blackbaud LMS. It adds cleaner layouts, assignment tools, easier navigation, and other useful features. The extension is designed primarily teachers, but it also provides utility to teachers and administrators.

## Highlights

| Area                        | Improvements                                                                                                                                                                           |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **UI & page layout**        | Clearer, cleaner, and more refined navigation and pages. Consistent controls and design, a cleaner Assignment Center, and polished styling, including a better Classes menu.           |
| **Assignments**             | Preview instructions and attachments beside the list, and mark completed work more quickly.                                                                                            |
| **Performance**             | Smoother navigation between pages using caching, prerendering, and other performance techniques.                                                                                       |
| **Directories and rosters** | A redesigned, faster directory layout and convenient roster tools. Copy roster names or emails, and open full-size profile photos.                                                     |
| **Sign-in**                 | Tired of logging to Blackbaud LMS every day after being signed out automatically? Skip having to log in every day. Sign in with one button, without wasting time on repetitive clicks. |
| **Everyday details**        | Useful tab titles that make sense, a recognizable tab icon, and more.                                                                                                                  |

## Install

Download Blackbaud Next for Chrome, Edge, Helium, and other Chromium-based browsers by [installing it via the Chrome Web Store](https://chromewebstore.google.com/detail/blackbaud-next-supercharg/ofadcfkogaiddhcmbabpgidjimnkfkij).

## Privacy

Blackbaud Next uses your existing school session and access permissions. Assignment, roster, and directory data used by its tools stays in memory; the extension does not save those records to extension storage or send them to a separate service. Directory tools respect Blackbaud’s publication settings.

Your preferences, including an optional Google account email or domain, are saved through Chrome’s extension storage and may sync with Chrome Sync. Temporary sign-in state lasts only for the browser session. The extension has no analytics and never enters passwords or bypasses authentication challenges.

It runs on school portal pages and Blackbaud and Google sign-in pages to provide these features. No separate Blackbaud Next account is required, and no extra servers will ever be contacted as a result of the extension. Everything is local.
